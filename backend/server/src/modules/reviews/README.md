# Reviews and KaamScore module — planned

## Responsibility
Collect eligible reviews, moderate reports, and calculate transparent work-history indicators.

## Rules
- Reviews must reference an eligible booking.
- NLP/keyword flags are prompts for human review, not automatic proof of misconduct.
- Do not expose private review/report metadata.
- Document scoring inputs and avoid penalizing workers for unanswered calls or legitimate declines.
- Add tests for score calculations and moderation rules.
